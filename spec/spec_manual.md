- Description: [The system shall explicitly disclose all subscriptions terms before a users applies to a free trial.  ]
- Source Persona: [ Unsatisfied Subscriber]
- Traceability: [Derived from review group G1]

# Requirement ID: FR2

- Description: [The system shall not automatically make a user subscribe following the end of their free trial.  ]
- Source Persona: [Unsatisfied Subscriber]
- Traceability: [Derived from review group G1]
- Acceptance Criteria: [Given a user has signed up for a free trial, When the free trail ends, Then the system shall not automatically lock the user into a payed subscription.  ]
